# Fipe Park - Sistema de Gerenciamento de Veículos

Sistema para gerenciar veículos cadastrados em um estacionamento, revenda ou locadora. Permite cadastro, edição e remoção de veículos, além de buscar marcas e modelos diretamente da API FIPE da Brasil API.

## **Tecnologias Usadas**

- **React** com **TypeScript**
- **Vite**
- **Redux** para gerenciamento de estado
- **Redux-Saga** para controle de efeitos colaterais
- **Tailwind CSS** para estilização

## **Instruções**

### Clonar o Repositório

Clone este repositório para o seu ambiente local usando o comando abaixo no terminal de sua preferência:

git clone https://github.com/Mateus-Caldarte/fipe-park.git

## Como rodar o projeto

- **Entre na pasta no projeto com o comando abaixo**

- **cd fipe-park**

## Instale as depenências com o comando abaixo

- **npm install**

## Rode o projeto com o comando abaixo

- **npm run dev - quando abrir a url local no terminal basta segurar o ctrl ou command + clique na mesma**
